# Чат MAX через GREEN-API

Тестовое задание: простой интерфейс для отправки и получения текстовых сообщений в MAX.

## Стек

- React + TypeScript (строгая проверка типов)
- Vite
- CSS Modules
- Oxlint

Роутер пока не используется: приложение предполагает форму подключения и экран чата.

## Запуск

```sh
npm install
npm run dev
```

Адрес локального сервера появится в терминале.

## Проверки и сборка

```sh
npm run lint
npm run build
npm run preview
```

`build` проверяет TypeScript и создаёт сборку в `dist`. `preview` запускает локальный просмотр сборки.

## Структура

```text
src/
  App.tsx          # Корневой компонент
  App.module.css   # Стили компонента
  index.css        # Глобальные стили
  main.tsx         # Точка входа
  styles/
    colors.css     # Общая палитра MAX
```

## Цвета

Палитра находится в `src/styles/colors.css` и подключена глобально через `src/index.css`.
Используйте CSS-переменные в стилях компонентов: `color: var(--color-text-primary)`.
Для исходящих сообщений предусмотрен `background: var(--gradient-message-outgoing)`.
Цвета интерфейса чата подобраны по его скриншоту. Фирменные цвета `--color-brand-*`
взяты из HEX-значений на предоставленном скриншоте палитры MAX.
Для экрана подключения используются фиолетовый акцент `--color-brand-blue-giant`
и светлый фон `--gradient-brand-light`. Также доступен `--gradient-brand-linear`.
Градиенты воспроизведены приблизительно по визуальному образцу.
